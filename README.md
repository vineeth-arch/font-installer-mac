# font-installer-mac

> **Superseded.** This repository is an early, empty placeholder for a macOS font installer. The working tool is **[font-drop](https://github.com/vineeth-arch/font-drop)**.

## Use font-drop instead

font-drop is a small macOS menu-bar app. Drop a `.zip` of fonts into a watched folder and the fonts are installed automatically. It prefers OTF over TTF, never overwrites an installed font, never moves or deletes your files, and copes with cloud-only files, nested zips and corrupt or password-protected archives.

```bash
git clone https://github.com/vineeth-arch/font-drop.git
cd font-drop
zsh -f font-drop.zsh setup ~/FontDrop
```
